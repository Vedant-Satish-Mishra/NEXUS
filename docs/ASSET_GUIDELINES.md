# NEXUS asset guidelines

## Known assets

The supplied NEXUS logos and concept images exist outside the future application repository; copy them into a versioned project asset directory only after confirming usage rights and desired final format. Do not reference unverified asset paths in code.

## Rules

- Use SVG for the final logo/icons when an editable approved source exists; PNG/WebP/AVIF for raster screenshots/illustrations.
- Provide meaningful alt text; decorative imagery uses empty alt text.
- Use responsive images with explicit dimensions to prevent layout shift.
- Prefer product-relevant diagrams/screens over random stock photos.
- Name assets by purpose, e.g. `nexus-logo-dark.svg`, `chat-plan-approval.webp`.
- Keep icon style consistent; do not mix outline, filled, and hand-drawn icon families without a deliberate role.
