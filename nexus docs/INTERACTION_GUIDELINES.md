# NEXUS interaction guidelines

Every visible control must have an immediate, meaningful result.

- **Links:** navigate; external links state that they open externally.
- **Buttons:** action controls only; disabled buttons explain why when discoverability matters.
- **Menus/tabs/filters:** have keyboard navigation, selected state, and no hidden destructive default.
- **Search:** debounced only when necessary, preserves query, offers clear/no-results state.
- **Pagination:** only where result volumes justify it; retain filter context.
- **Tooltips:** supplementary, never the only label for a vital action.
- **Plan steps:** reorder/edit/delete must be clearly saved before approval.
- **Run controls:** Resume only when paused; Cancel confirms consequence; status updates are announced.

Acceptance: no clickable decoration, no dead end after error, no action silently changes consent/security settings.
